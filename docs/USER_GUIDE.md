# Руководство пользователя DOS95

## Запуск

Для автономной версии дважды щёлкните `DOS95.exe`. Окно консоли показывает фактический локальный адрес, а браузер открывает DOS-терминал. Если браузер не открылся, скопируйте адрес вида `http://127.0.0.1:3000/` из консоли.

Введите `WIN95` или `WIN`, чтобы загрузить рабочий стол Windows 95 в текущей вкладке. Файлы, созданные в DOS до перехода, остаются на общей VFS и сразу видны в Проводнике. Прямой адрес `/win95` можно использовать для закладки или диагностики.

Не запускайте две копии из одной папки без необходимости: каждая копия выберет собственный порт и токен API, но использует общий виртуальный диск текущего пользователя.

## Интерфейсы

Рабочий стол Windows 95 содержит меню «Пуск», панель задач, DOS Prompt, Проводник, Блокнот, Калькулятор, DOCTOR и окно «О программе». Окна можно перемещать, изменять их размер, сворачивать, разворачивать и закрывать.

В DOS Prompt вводите команды после приглашения `C:\>`. Команда `WIN95` открывает графический интерфейс, `HELP` показывает список команд, а `HELP DOCTOR` — краткую справку по ELIZA.

## Виртуальный диск

DOS95 не предоставляет командному интерпретатору доступ к настоящему диску компьютера. Все пути ограничены виртуальным диском `C:`. Проводник и DOS Prompt работают с одним состоянием VFS.

Данные автоматически сохраняются в:

```text
%LOCALAPPDATA%\DOS95\vfs.json
```

Запись выполняется через временный файл. При повреждении JSON исходный файл сохраняется под именем `vfs.corrupt-<timestamp>.json`, а приложение загружает чистое состояние.

Для резервного копирования завершите DOS95 и скопируйте весь каталог `%LOCALAPPDATA%\DOS95`. Не редактируйте `vfs.json` во время работы приложения.

## Проводник и Блокнот

Проводник поддерживает просмотр, создание, чтение, редактирование, копирование, перемещение и удаление файлов/папок. Имена с пробелами допустимы. Размер одного содержимого, отправляемого через API, ограничен 256 КБ.

При удалении непустой папки требуется рекурсивное подтверждение. Read-only элементы и корень диска защищены от опасных операций.

## DOCTOR / ELIZA

Введите `DOCTOR` или откройте соответствующее окно. Для завершения сеанса используйте `QUIT` или `EXIT`.

- Без `OPENAI_API_KEY` используется полностью локальная ELIZA.
- С ключом используется настроенная модель OpenAI и два этапа модерации.
- При сетевой ошибке, ошибке ключа или провайдера выполняется fallback на локальную ELIZA.
- DOCTOR — поддерживающий виртуальный собеседник, а не врач и не экстренная служба.

Настройка ключа и модели описана в [OPENAI_SETUP.md](../OPENAI_SETUP.md), ограничения защиты — в [SECURITY.md](SECURITY.md).

## Завершение и устранение проблем

Пункт «Завершение работы» штатно останавливает автономный процесс. При запуске из исходников shutdown API отключён — остановите сервер сочетанием `Ctrl+C`.

Если приложение не запускается:

1. Проверьте, не заблокирован ли неподписанный EXE Windows SmartScreen.
2. Запустите EXE из PowerShell, чтобы увидеть диагностическое сообщение.
3. Проверьте права записи в `%LOCALAPPDATA%\DOS95`.
4. Временно переименуйте `.env`, чтобы исключить ошибочную конфигурацию OpenAI.
5. Сверьте SHA-256 с `DOS95.exe.sha256`.
