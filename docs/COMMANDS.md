# Справочник команд DOS95

Команды регистронезависимы. Путь может быть абсолютным (`C:\TEMP\A.TXT`) или относительным. Имена с пробелами заключаются в двойные кавычки.

## Файлы и каталоги

| Команда | Назначение |
|---|---|
| `DIR [путь]` | Список файлов и каталогов |
| `CD [путь]`, `CHDIR` | Показать или сменить текущий каталог |
| `CD..`, `CD\`, `C:` | Родительский каталог, корень, диск C |
| `TYPE <файл>` | Вывести содержимое файла |
| `MORE <файл>` | Вывести содержимое с разделителями каждые 20 строк |
| `COPY <источник> <назначение>` | Скопировать файл |
| `DEL <файл>` | Удалить файл; алиасы `DELETE`, `ERASE` |
| `MD <каталог>` | Создать каталог; алиас `MKDIR` |
| `RD <каталог>` | Удалить пустой каталог; алиас `RMDIR` |
| `RD /S <каталог>` | Рекурсивно удалить каталог, если нет read-only содержимого |
| `REN <старый> <новый>` | Переименовать; алиас `RENAME` |
| `MOVE <источник> <назначение>` | Переместить файл или каталог |
| `TREE [путь]` | Показать дерево каталогов |
| `ATTRIB <путь>` | Показать `R` для read-only или `A` для обычного объекта |

Пример:

```dos
MD "Мои файлы"
ECHO Первая строка > "Мои файлы\note.txt"
TYPE "Мои файлы\note.txt"
COPY "Мои файлы\note.txt" C:\TEMP\copy.txt
```

## Системные и дополнительные команды

| Команда | Назначение |
|---|---|
| `CLS`, `CLEAR` | Очистить экран |
| `HELP [команда]`, `?` | Получить справку |
| `VER`, `DATE`, `TIME` | Версия, дата и время |
| `ECHO <текст>` | Вывести текст |
| `PROMPT [значение]` | Показать или изменить приглашение текущей сессии |
| `SET [ИМЯ=значение]` | Показать или изменить виртуальные переменные текущей сессии |
| `PATH [значение]` | Показать или изменить виртуальный PATH |
| `VOL`, `MEM` | Виртуальная информация о диске и памяти |
| `CALC <выражение>` | Калькулятор `+ - * /` со скобками; `eval` не используется |
| `BANNER <текст>` | ASCII-баннер |
| `FORTUNE` | Случайная цитата |
| `DOCTOR` | Начать сеанс ELIZA; выход — `QUIT`/`EXIT` |
| `WIN95`, `WIN` | Открыть интерфейс Windows 95 |
| `EXIT` | Сообщить способ выхода из браузерной версии |

`SET`, `PATH` и `PROMPT` не меняют реальные переменные Windows и не дают доступ к ОС.

## Перенаправление вывода

`>` перезаписывает файл выводом команды, `>>` дописывает вывод. Операция выполняется только внутри VFS.

```dos
ECHO Строка 1 > notes.txt
ECHO Строка 2 >> notes.txt
DIR > files.txt
VER >> report.txt
```

Символ `>` внутри кавычек считается частью текста:

```dos
ECHO "1 > 0" > result.txt
```

Если команда завершилась ошибкой, перенаправляемый файл не изменяется. Незакрытая кавычка и отсутствующее имя файла возвращают явную ошибку разбора.
