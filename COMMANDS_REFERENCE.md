# 📖 Справочник команд DOS Web System

## 🗂️ Файловые команды

### DIR [путь]
Показывает список файлов и каталогов

```dos
C:\> DIR
C:\> DIR C:\WINDOWS
C:\> DIR DOS
```

**Вывод:** Список с датой, временем, размером и типом (<DIR> или размер в байтах)

---

### CD [путь]
Меняет текущий каталог

```dos
C:\> CD DOS
C:\DOS> CD..           (без пробела!)
C:\DOS> CD\            (в корень)
C:\> C:                (перейти на C:\)
C:\> CD WINDOWS\SYSTEM
```

**Использование:**
- `CD` без параметров - показать текущий каталог
- `CD путь` - перейти в указанный каталог
- `CD..` - на уровень вверх (можно без пробела!)
- `CD\` - в корень диска C:\
- `C:` - перейти на диск C:\
- `..` - на уровень вверх
- `.` - текущий каталог
- `\` - корень диска

---

### TYPE <файл>
Выводит содержимое текстового файла

```dos
C:\> TYPE README.TXT
C:\> TYPE AUTOEXEC.BAT
C:\DOS> TYPE COMMAND.COM
```

---

### MORE <файл>
Постраничный просмотр файла (по 20 строк)

```dos
C:\> MORE README.TXT
C:\> MORE AUTOEXEC.BAT
```

**Удобно для длинных файлов!** Выводит с пометками "-- Ещё --"

---

### COPY <источник> <назначение>
Копирует файл

```dos
C:\> COPY README.TXT BACKUP.TXT
C:\> COPY DOS\COMMAND.COM C:\TEMP\COMMAND.COM
```

---

### DEL <файл>
Удаляет файл (синонимы: DELETE, ERASE)

```dos
C:\> DEL TEMP.TXT
C:\> DELETE BACKUP.TXT
C:\> ERASE OLD.BAT
```

⚠️ Нельзя удалить readonly файлы!

---

### MD <каталог>
Создает новый каталог (синоним: MKDIR)

```dos
C:\> MD NEWDIR
C:\> MKDIR TEMP\BACKUP
```

---

### RD <каталог>
Удаляет пустой каталог (синоним: RMDIR)

```dos
C:\> RD TEMP
C:\> RMDIR OLDDIR
```

⚠️ **Важно:** Каталог должен быть пустым!

---

### REN <старое> <новое>
Переименовывает файл (синоним: RENAME)

```dos
C:\> REN OLD.TXT NEW.TXT
C:\> RENAME FILE1.BAT FILE2.BAT
```

---

### MOVE <источник> <назначение>
Перемещает файл

```dos
C:\> MOVE FILE.TXT TEMP\FILE.TXT
```

---

### TREE [путь]
Показывает дерево каталогов

```dos
C:\> TREE
C:\> TREE DOS
```

**Вывод:** Визуальное дерево со всеми подкаталогами

---

### ATTRIB <файл>
Показывает атрибуты файла

```dos
C:\> ATTRIB README.TXT
```

**Атрибуты:**
- `R` - Readonly (только чтение)
- `A` - Archive (архивный)

## 🎮 Специальные команды

### DOCTOR 🤖
Запускает AI психотерапевта на базе GPT-4O

```dos
C:\> DOCTOR
```

**Интерактивная сессия:**
```
╔═══════════════════════════════════════════════════╗
║      ELIZA - AI Психотерапевт (GPT-4O)            ║
║      Виртуальная терапевтическая сессия           ║
╚═══════════════════════════════════════════════════╝

Здравствуйте. Я ваш AI психотерапевт.
Расскажите мне, что вас беспокоит.

(Введите QUIT для выхода)

YOU> Мне грустно
DOCTOR> Я понимаю, что вам сейчас нелегко. 
        Расскажите подробнее, что вызывает эту грусть?

YOU> Проблемы на работе
DOCTOR> Рабочие проблемы могут быть очень стрессовыми.
        Что именно происходит на работе?

YOU> QUIT
Сеанс завершен. Берегите себя!
```

**Команды в режиме DOCTOR:**
- Любой текст - отправить сообщение терапевту
- `QUIT` или `EXIT` - выйти из режима

⚠️ **Требует OpenAI API ключ!** Без ключа работает как классическая ELIZA.

---

### CALC <выражение>
Калькулятор для математических выражений

```dos
C:\> CALC 2 + 2
2 + 2 = 4

C:\> CALC 10 * 5 + 3
10 * 5 + 3 = 53

C:\> CALC (100 - 25) / 5
(100 - 25) / 5 = 15
```

**Поддерживает:**
- Сложение: `+`
- Вычитание: `-`
- Умножение: `*`
- Деление: `/`
- Скобки: `()`
- Десятичные числа: `3.14`

---

### BANNER <текст>
Создает ASCII баннер из текста

```dos
C:\> BANNER DOS

  D  D    OOO    SSS  
  D  D   O   O  S     
  DDD    O   O   SSS  
  D  D   O   O      S 
  D  D    OOO    SSS  
```

**Ограничения:** Поддерживает только английские буквы A-Z

---

### FORTUNE
Показывает случайную мотивационную цитату

```dos
C:\> FORTUNE

 ┌────────────────────────────────────────────────────────┐
 │ Единственный способ сделать великую работу - любить    │
 │ то, что ты делаешь.                                    │
 └────────────────────────────────────────────────────────┘
```

| Клавиша | Действие |
|---------|----------|

## ➡️ Перенаправление вывода

### Оператор >
Сохраняет вывод команды в файл (перезаписывает)

```dos
C:\> ECHO Hello World > test.txt
C:\> DIR > listing.txt
C:\> VER > version.txt
```

**Результат:** Создаётся или перезаписывается файл

---

### Оператор >>
Добавляет вывод команды к файлу

```dos
C:\> ECHO First line > log.txt
C:\> ECHO Second line >> log.txt
C:\> ECHO Third line >> log.txt
```

**Результат:** Текст добавляется в конец файла

---

### Примеры перенаправления

```dos
C:\> ECHO ==== System Info ==== > info.txt
C:\> VER >> info.txt
C:\> DATE >> info.txt
C:\> TIME >> info.txt
C:\> MEM >> info.txt
C:\> TYPE info.txt
```

**Полезно для:**
- Создания файлов быстро
- Сохранения результатов команд
- Логирования
- Экспорта данных

## 💡 Полезные примеры

### Навигация по каталогам
```dos
C:\> DIR                    # Посмотреть что здесь
C:\> CD DOS                 # Перейти в DOS
C:\DOS> DIR                 # Посмотреть содержимое
C:\DOS> CD ..               # Вернуться назад
C:\> CD WINDOWS\SYSTEM      # Перейти в подкаталог
```

### Работа с файлами
```dos
C:\> TYPE README.TXT        # Прочитать файл
C:\> COPY README.TXT BACKUP.TXT  # Скопировать
C:\> REN BACKUP.TXT OLD.TXT      # Переименовать
C:\> DEL OLD.TXT            # Удалить
```

### Создание структуры
```dos
C:\> MKDIR MYPROJECT        # Создать папку
C:\> CD MYPROJECT           # Зайти в нее
C:\MYPROJECT> MKDIR SRC     # Создать подпапку
C:\MYPROJECT> MKDIR DOCS    # Еще одну
C:\MYPROJECT> TREE          # Посмотреть структуру
```

### Информация о системе
```dos
C:\> VER                    # Версия
C:\> DATE                   # Дата
C:\> TIME                   # Время
C:\> MEM                    # Память
C:\> VOL                    # Том
```

### Развлечения
```dos
C:\> FORTUNE                # Случайная цитата
C:\> BANNER HELLO           # ASCII баннер
C:\> CALC 1234 * 5678       # Вычисления
C:\> DOCTOR                 # AI терапевт
```

## ⚠️ Важные примечания

1. **Case Insensitive:** Команды не чувствительны к регистру
   - `DIR`, `dir`, `DiR` - все работает

2. **Пути:**
   - Абсолютный: `C:\DOS\COMMAND.COM`
   - Относительный: `DOS\COMMAND.COM`
   - Родительский: `..\WINDOWS`

3. **Readonly файлы:**
   - Нельзя удалить
   - Нельзя изменить
   - Обычно системные файлы

4. **Несуществующие команды:**
   ```dos
   C:\> INVALID
   Неверная команда или имя файла: INVALID
   Используйте HELP для списка команд.
   ```
