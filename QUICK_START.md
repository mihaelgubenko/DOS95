# Быстрый старт DOS95

## Для пользователя

1. Скачайте папку `dist` целиком.
2. При необходимости проверьте SHA-256 по файлу `DOS95.exe.sha256`.
3. Запустите `DOS95.exe` — установка не требуется.
4. В открывшемся DOS-терминале введите `WIN95`, чтобы загрузить графическую среду.
5. Если браузер не открылся, используйте адрес, напечатанный в окне приложения.

Данные виртуального диска находятся в `%LOCALAPPDATA%\DOS95`. Удаление EXE не удаляет пользовательские файлы.

## Для разработчика

```powershell
npm ci
npm run test:setup
npm run verify
npm start
```

Для новой автономной сборки:

```powershell
npm run build:win
npm run smoke:exe
```

Для полного релизного прогона используйте `npm run release:check`. Подпись EXE выполняется после сборки по инструкции [docs/RELEASE.md](docs/RELEASE.md).

OpenAI необязателен. Скопируйте `.env.example` в `.env`, если нужен сетевой режим `DOCTOR`; иначе используется встроенная ELIZA.
