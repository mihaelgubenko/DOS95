# 🚀 Быстрый старт DOS Web System

## Установка и запуск за 3 минуты

### 1️⃣ Установите зависимости

```bash
cd dos-web-system
npm install
```

### 2️⃣ Настройте OpenAI API (опционально)

Создайте файл `.env`:

```bash
OPENAI_API_KEY=sk-ваш-ключ-OpenAI
PORT=3000
GPT_MODEL=gpt-4o
```

**Важно:** Без API ключа команда DOCTOR будет работать в режиме классической ELIZA (без GPT-4O).

### 3️⃣ Запустите сервер

```bash
npm start
```

### 4️⃣ Откройте браузер

Перейдите на: **http://localhost:3000**

## 🎯 Первые команды для проверки

```dos
HELP          - Список всех команд
VER           - Версия системы
DIR           - Список файлов
CD DOS        - Перейти в папку
CD..          - На уровень вверх
CD\           - В корень диска
TYPE README.TXT - Прочитать файл
MORE README.TXT - Постраничный просмотр
ECHO Hi > file.txt - Создать файл
MD TEMP       - Создать папку
RD TEMP       - Удалить пустую папку
TREE          - Дерево каталогов
FORTUNE       - Случайная цитата
BANNER DOS    - ASCII баннер
CALC 2 + 2    - Калькулятор
DOCTOR        - AI психотерапевт (требует OpenAI API)
```

## 🔑 Где взять OpenAI API ключ?

1. Зарегистрируйтесь на https://platform.openai.com
2. Перейдите в раздел "API Keys"
3. Создайте новый ключ
4. Скопируйте ключ в `.env` файл

**Формат ключа:** `sk-proj-...` или `sk-...`

---

## ❓ Проблемы?

### Ошибка "Cannot find module"
```bash
npm install
```

### Порт 3000 занят
Измените PORT в `.env` файле

### DOCTOR не отвечает
Проверьте правильность API ключа в `.env`
