# История изменений

Формат основан на Keep a Changelog, версии следуют Semantic Versioning.

## [1.1.0] — 2026-08-16

### Добавлено

- долговечное атомарное хранение виртуальной файловой системы;
- структурированный файловый API и полный набор unit/integration/E2E тестов;
- локальные guardrails, модерация ввода/ответа и Responses API для DOCTOR;
- process-token, Host/Origin validation, CSP и rate limiting для локального API;
- автономная Windows x64 сборка, checksum и smoke-тест без Node.js;
- подробная пользовательская, API, security, development и release-документация;
- PowerShell-сценарий Authenticode подписи через сертификат Windows.

### Изменено

- модель OpenAI по умолчанию — `gpt-5.6-terra`, разрешены только Terra/Luna/Sol;
- версия терминала теперь берётся из `package.json`;
- браузерные mutation requests централизованы в защищённом API-клиенте;
- устаревшие руководства консолидированы, исторические материалы вынесены из активной ветки.
- терминал стал светлее и контрастнее при сохранении чёрно-зелёного DOS-стиля.

### Исправлено

- автономный запуск снова начинает с DOS, а `WIN95`/`WIN` загружает рабочий стол в текущей вкладке без popup;
- успешные команды в окне Windows 95 больше не показывают ложную ошибку связи из-за отсутствующего status bar;
- сетевые, HTTP/JSON и интерфейсные ошибки терминала теперь различаются;
- CSS-селектор визуального режима DOCTOR применяется к самому терминалу.

### Безопасность

- API-ключ остаётся только на серверной стороне и не включается в EXE;
- модель не получает tools, запросы используют `store: false` и псевдонимный `safety_identifier`;
- тесты изолированы от пользовательского `.env` и не обращаются к реальному OpenAI.

## [1.0.0] — 2025-10-09

- исходная DOS-среда, VFS, терминал, интерфейс Windows 95 и базовая ELIZA/OpenAI интеграция.
