## 🎯 Как это работает

### 1️⃣ Откройте DOS терминал

Браузер должен был открыться автоматически, или откройте:
```
http://localhost:3000
```

### 2️⃣ Введите команду WIN95

В DOS терминале:
```dos
C:\> WIN95
```

**Или сокращённо:**
```dos
C:\> WIN
```

### 3️⃣ Готово! 🎉

Откроется новое окно с Windows 95 интерфейсом!

## 🎨 Преимущества

### ✅ Лучше чем было раньше:

**Было:**
- Windows 95 по умолчанию
- DOS спрятан на /dos
- Нужно вручную переключаться

**Стало:**
- ✅ DOS по умолчанию (привычно!)
- ✅ Win95 по команде (быстро!)
- ✅ Оба работают одновременно
- ✅ Не нужно редактировать URL

### ✅ Удобно:

1. **Быстрые команды** → DOS терминал
2. **Визуализация** → Win95 GUI
3. **Создавайте файлы в DOS**, **просматривайте в Win95**

---

## 💡 Примеры использования

### Пример 1: Работа с файлами

**В DOS (первое окно):**
```dos
C:\> ECHO Hello Windows 95! > greeting.txt
C:\> DIR
C:\> TYPE greeting.txt
```

**В Win95 (второе окно):**
- Откройте Проводник 📂
- Найдите файл `GREETING.TXT`
- Двойной клик - прочитайте содержимое!

### Пример 2: Системная информация

**В DOS:**
```dos
C:\> VER > info.txt
C:\> DATE >> info.txt
C:\> TIME >> info.txt
C:\> MEM >> info.txt
```

**В Win95:**
- Проводник → `INFO.TXT` → Двойной клик
- Полная системная информация!

### Пример 3: Параллельная работа

**Окно 1 - DOS терминал:**
```dos
C:\> CD DOS
C:\DOS> DIR
C:\DOS> TYPE COMMAND.COM
```

**Окно 2 - Win95 GUI:**
- Перетаскивайте окна
- Работайте в Проводнике
- Визуализируйте структуру папок
