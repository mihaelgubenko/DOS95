## 🏗️ ARCHITECTURE OVERVIEW

### Цель проекта
DOS95 - это веб-эмулятор MS-DOS и Windows 95 с виртуальной файловой системой, реализованный как полнофункциональная веб-система с GUI интерфейсом в стиле Windows 95.

### Ключевые принципы
1. **Backward Compatibility** - Все существующие команды должны работать после любых изменений
2. **VFS Isolation** - Виртуальная ФС не имеет доступа к реальной системе
3. **Multi-Modal Interface** - DOS терминал + Win95 GUI работают параллельно
4. **Session Persistence** - Состояние пользователя сохраняется между командами
5. **Graceful Fallbacks** - При недоступности API используется запасной вариант

## 🛡️ STABILITY ANCHORS (Якоря стабильности)

### КРИТИЧЕСКИЕ ФАЙЛЫ - НЕ ИЗМЕНЯТЬ БЕЗ АУДИТА:

1. **`virtualFS.js`** - База файловой системы
   - Любые изменения → проверка всех файловых команд
   - Обязательно: тесты `DIR`, `CD`, `COPY`, `DEL`, `MD`, `RD`

2. **`handler.js`** - Маршрутизация команд
   - Любые изменения → проверка всех команд
   - Обязательно: проверка `doCommand()` и `executeCommand()`

3. **`server.js`** - API endpoints
   - Изменения → проверка HTTP запросов
   - Обязательно: `/api/command`, `/api/file`

4. **`win95-manager.js`** - Window management
   - Изменения → проверка окна, drag/resize
   - Обязательно: открытие всех типов окон
