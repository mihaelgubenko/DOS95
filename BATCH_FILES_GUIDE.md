# 🚀 Руководство по BAT файлам

## 📁 Доступные батники

### 1️⃣ `start.bat` - Главный запуск сервера
**Запускает Node.js сервер и открывает браузер**

```bash
start.bat
```

**Что делает:**
- ✅ Проверяет Node.js
- ✅ Устанавливает зависимости (если нужно)
- ✅ Проверяет .env файл
- ✅ Запускает сервер на порту 3000
- ✅ Автоматически открывает http://localhost:3000

**Используйте для первого запуска!**

---

### 2️⃣ `start-win95.bat` - Открыть Windows 95 интерфейс
**Открывает Windows 95 GUI в браузере**

```bash
start-win95.bat
```

**Что делает:**
- Открывает http://localhost:3000
- Показывает Windows 95 интерфейс
- ⚠️ Требует запущенный сервер!

**Используйте когда сервер уже работает**

---

### 3️⃣ `start-dos.bat` - Открыть классический DOS терминал
**Открывает Classic DOS терминал в браузере**

```bash
start-dos.bat
```

**Что делает:**
- Открывает http://localhost:3000/dos
- Показывает зелёный DOS терминал
- ⚠️ Требует запущенный сервер!

**Используйте для ретро-терминала**

---

### 4️⃣ `install.bat` - Установка зависимостей
**Устанавливает npm пакеты**

```bash
install.bat
```

**Что делает:**
- Устанавливает все npm зависимости
- Создаёт .env из .env.example

**Используйте один раз при первой установке**

---

## 🎯 Порядок использования

### Первый запуск:

```bash
# 1. Установка (один раз)
install.bat

# 2. Запуск сервера
start.bat
```

Сервер запустится и откроет Windows 95 интерфейс автоматически!

---

### Обычное использование:

**Вариант 1: Запустить всё сразу**
```bash
start.bat
```
Запускает сервер + открывает Windows 95

**Вариант 2: Запустить сервер отдельно**
```bash
# В одном окне терминала - запустить сервер
npm start

# В другом окне - открыть интерфейс
start-win95.bat   # для Windows 95
# или
start-dos.bat     # для Classic DOS
```

---

## 🖱️ Двойной клик по файлам

**Просто дважды кликните по нужному .bat файлу!**

- 🖱️ `start.bat` → Запустить сервер + Windows 95
- 🖱️ `start-win95.bat` → Открыть Windows 95 (если сервер работает)
- 🖱️ `start-dos.bat` → Открыть DOS терминал (если сервер работает)

---

## ⚙️ Остановить сервер

**Нажмите `Ctrl + C` в окне с запущенным сервером**

Или закройте окно терминала.

---

## 🔧 Если что-то пошло не так

### Сервер не запускается?

1. Проверьте Node.js:
   ```bash
   node --version
   ```

2. Переустановите зависимости:
   ```bash
   install.bat
   ```

3. Попробуйте запустить вручную:
   ```bash
   npm start
   ```

### Браузер не открывается?

Откройте вручную:
```
http://localhost:3000        - Windows 95
http://localhost:3000/dos    - Classic DOS
```

### Порт 3000 занят?

Измените порт в `.env`:
```
PORT=3001
```
