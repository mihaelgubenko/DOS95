# 🖥️ Windows 95 Interface - Руководство пользователя

## 🎉 Добро пожаловать в Windows 95!

DOS Web System теперь имеет полноценный интерфейс Windows 95 с графическими окнами, меню "Пуск", панелью задач и файловым проводником!

1. **Запустите сервер:**
   ```bash
   npm start

   start.bat

2. **Откройте браузер:**
   ```

## 🪟 Работа с окнами

### Управление окнами

Каждое окно Windows 95 имеет:

**Заголовок окна** (Title Bar):
- 📟 **Иконка** - Тип приложения
- **Название** - Имя окна
- **_** - Свернуть (Minimize)
- **□** - Развернуть/Восстановить (Maximize/Restore)
- **×** - Закрыть (Close)

### Перетаскивание окон

1. **Захватите** заголовок окна левой кнопкой мыши
2. **Перетащите** окно в нужное место
3. **Отпустите** кнопку мыши

### Изменение размера окон

1. **Наведите** курсор на правый нижний угол окна
2. **Захватите** маркер изменения размера (↘)
3. **Перетащите** для изменения размера

### Переключение между окнами

Несколько способов:
- **Клик** на окно для активации
- **Клик** на кнопку окна в панели задач
- **Клик** на свёрнутое окно для восстановления

### Состояния окон

- **Активное** - Синий заголовок, окно на переднем плане
- **Неактивное** - Серый заголовок
- **Свёрнутое** - Скрыто, только в панели задач
- **Развёрнутое** - На весь экран (кроме панели задач)

## 📟 MS-DOS Prompt (Терминал)

Полноценный DOS терминал в окне Windows 95!

### Как открыть:
- Двойной клик на иконке **MS-DOS Prompt** на рабочем столе
- Или: Пуск → MS-DOS Prompt

### Особенности:
- Все **26+ DOS команд** работают
- История команд (↑/↓)
- Перенаправление вывода (>, >>)
- Команда **DOCTOR** для AI психотерапевта
- Виртуальная файловая система

### Примеры команд:
```dos
C:\> DIR                          - Список файлов
C:\> CD DOS                       - Перейти в папку
C:\> TYPE README.TXT              - Прочитать файл
C:\> ECHO Hello > test.txt        - Создать файл
C:\> DOCTOR                       - Запустить AI психотерапевта
C:\> HELP                         - Справка по командам
```

## 📂 Проводник (File Explorer)

Графический файловый менеджер для виртуальной ФС!

### Как открыть:
- Двойной клик на иконке **Проводник** на рабочем столе
- Или: Пуск → Проводник

### Интерфейс:

**Панель инструментов:**
- **◄** - Назад (история)
- **▲** - Вверх (родительская папка)
- **📂** - Текущий путь
- **🔄** - Обновить

**Список файлов:**
- Таблица с колонками: Имя, Размер, Тип
- **Двойной клик** на папку - открыть
- **Двойной клик** на файл - просмотр содержимого

**Статус бар:**
- Показывает количество объектов

### Навигация:
```
📁 C:\
  ├── 📁 DOS
  │   ├── 📄 COMMAND.COM
  │   └── 📄 FORMAT.COM
  ├── 📁 WINDOWS
  │   └── 📁 SYSTEM
  ├── 📁 TEMP
  └── 📄 README.TXT
```

### Функции:
- ✅ Просмотр папок
- ✅ Навигация по дереву
- ✅ Просмотр файлов
- ✅ Отображение размеров
- ✅ Иконки типов файлов

## 🧠 ELIZA Psychotherapist

AI психотерапевт на базе GPT-4O в стиле классической ELIZA.

### Как использовать:

**Способ 1: Через DOS терминал**
```dos
C:\> DOCTOR
```

**Способ 2: Через меню**
- Пуск → ELIZA Psychotherapist
- Информационное окно с инструкциями

### Пример сессии:
```dos
C:\> DOCTOR

╔═══════════════════════════════════════════════════╗
║      ELIZA - AI Психотерапевт (GPT-4O)            ║
╚═══════════════════════════════════════════════════╝

Здравствуйте. Я ваш AI психотерапевт.
Расскажите мне, что вас беспокоит.

(Введите QUIT для выхода)

YOU> Мне грустно
DOCTOR> Что вызывает эту грусть?

YOU> QUIT
Сеанс завершен. Берегите себя!
```

## 💡 Советы и трюки

### 1. Многозадачность
Открывайте несколько окон одновременно:
- DOS терминал для команд
- Проводник для просмотра файлов
- О системе для справки

### 2. Удобная навигация
- Используйте кнопки **▲** в проводнике
- История команд в терминале (↑/↓)
- Сворачивайте неиспользуемые окна

### 3. Создание файлов
Создавайте файлы через терминал, просматривайте в проводнике:
```dos
C:\> ECHO Мой файл > test.txt
C:\> DIR
```
Затем откройте Проводник и увидите файл!

### 4. Эффективная работа
- Сворачивайте окна вместо закрытия
- Используйте панель задач для быстрого переключения
- Развернутые окна для полноэкранной работы

## 🐛 Известные особенности

### Виртуальная ФС
- Данные хранятся в памяти (теряются при перезапуске сервера)
- Нет реального доступа к диску (безопасность)

### Окна
- Окна не выходят за границы рабочего стола
- Минимальный размер: 200x100px

### Проводник
- Работает только с виртуальной ФС
- Нет drag & drop между окнами (пока)
