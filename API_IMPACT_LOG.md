## 🔄 WORKFLOW (Как использовать)

### Перед изменением:
1. Откройте этот файл
2. Найдите последнюю запись с `git commit hash`
3. Запустите все тесты из `REGRESSION_TESTS.md`
4. Убедитесь, что всё работает (PASS)
5. Создайте новую запись по шаблону

### При изменении:
1. Измените файл(ы)
2. Запустите соответствующие тесты
3. Запишите результаты в новую запись

### После изменения:
1. Зафиксируйте коммит
2. Добавьте `git commit hash` в запись
3. Если тесты FAIL → Откатите к предыдущей версии
4. Если тесты PASS → Продолжайте

## 📝 NOTES (Заметки)

### Best Practices:
- ✅ Делайте изменения в один файл за раз
- ✅ Тестируйте сразу после каждого изменения
- ✅ Коммитьте только рабочие версии
- ✅ Фиксируйте якорные версии для отката

### Anti-patterns:
- ❌ Не изменяйте несколько файлов без тестирования каждого
- ❌ Не игнорируйте ошибки в консоли
- ❌ Не коммитьте нерабочий код
