# 📝 Руководство по перенаправлению вывода в DOS95

## Как это работает?

В DOS95 вы можете **перенаправить вывод любой команды** прямо в файл, вместо того чтобы выводить его на экран.

## Синтаксис

### `>` - Создать новый файл или перезаписать существующий
```
команда > имя_файла.txt
```

### `>>` - Добавить к существующему файлу
```
команда >> имя_файла.txt
```

## 🎯 Как это работает внутри?

1. **Система парсит команду** и находит символ `>` или `>>`
2. **Выполняет команду** (например, ECHO, DIR, VER)
3. **Перехватывает вывод** команды
4. **Записывает в файл** вместо экрана
5. Если файл не существует - **создает его автоматически**
6. Если используется `>` - **перезаписывает** старое содержимое
7. Если используется `>>` - **добавляет** к существующему содержимому

## 📚 Примеры использования

### 1️⃣ Создать простой текстовый файл
```dos
ECHO Hello World > привет.txt
```
✅ Создаст файл `ПРИВЕТ.TXT` с текстом "Hello World"

### 2️⃣ Создать многострочный файл
```dos
ECHO Строка 1 > файл.txt
ECHO Строка 2 >> файл.txt
ECHO Строка 3 >> файл.txt
```
✅ Создаст файл с тремя строками

### 3️⃣ Сохранить список файлов
```dos
DIR > список.txt
```
✅ Сохранит вывод команды DIR в файл

### 4️⃣ Сохранить информацию о системе
```dos
VER > info.txt
DATE >> info.txt
TIME >> info.txt
MEM >> info.txt
```
✅ Создаст файл с полной информацией о системе

### 5️⃣ Создать заметку
```dos
ECHO Напоминание: купить молоко > note.txt
TYPE note.txt
```
✅ Создаст заметку и сразу прочитает её

### 6️⃣ Сохранить результаты калькулятора
```dos
CALC 2 + 2 > result.txt
CALC 10 * 5 >> result.txt
TYPE result.txt
```

### 7️⃣ Создать список дерева каталогов
```dos
TREE > структура.txt
TYPE структура.txt
```

### 8️⃣ Сохранить цитату
```dos
FORTUNE > цитата_дня.txt
TYPE цитата_дня.txt
```

### 9️⃣ Создать лог-файл
```dos
ECHO === Начало работы === > log.txt
DATE >> log.txt
DIR >> log.txt
ECHO === Конец работы === >> log.txt
```

### 🔟 Создать скрипт (будущая функция)
```dos
ECHO @ECHO OFF > autoexec.bat
ECHO ECHO Привет! >> autoexec.bat
ECHO DIR >> autoexec.bat
```

## ⚠️ Важные моменты

### ✅ Работает с любыми командами:
- ECHO, DIR, TYPE, VER, DATE, TIME
- CALC, FORTUNE, MEM, VOL
- TREE, SET, PATH
- И любыми другими!

### ❌ НЕ работает с:
- CLS (не выводит ничего)
- CD (не выводит ничего без аргументов)
- DOCTOR (специальный режим)

### 🔧 Особенности:

1. **Имена файлов** могут быть с пробелами или без
   ```dos
   ECHO Test > myfile.txt          ✅ Работает
   ECHO Test > my file.txt         ⚠️ Создаст "MY"
   ```

2. **Расширения** можно не указывать
   ```dos
   ECHO Test > myfile               ✅ Создаст MYFILE
   ```

3. **Файлы создаются** в текущей директории
   ```dos
   CD TEMP
   ECHO Test > file.txt             ✅ Создаст в C:\TEMP\FILE.TXT
   ```

4. **Абсолютные пути** тоже работают
   ```dos
   ECHO Test > C:\TEMP\file.txt     ✅ Создаст в C:\TEMP\
   ```

## 🎓 Практические задания

### Задание 1: Создать файл-визитку
```dos
ECHO =================== > card.txt
ECHO    МОЯ ВИЗИТКА >> card.txt
ECHO =================== >> card.txt
ECHO Имя: Иван >> card.txt
ECHO Email: ivan@mail.ru >> card.txt
TYPE card.txt
```

### Задание 2: Системный отчёт
```dos
ECHO === СИСТЕМНЫЙ ОТЧЁТ === > report.txt
VER >> report.txt
DATE >> report.txt
TIME >> report.txt
VOL >> report.txt
MEM >> report.txt
ECHO === ФАЙЛЫ === >> report.txt
DIR >> report.txt
TYPE report.txt
```

### Задание 3: Дневник
```dos
DATE > diary.txt
ECHO Сегодня был хороший день >> diary.txt
ECHO Изучил DOS команды >> diary.txt
TYPE diary.txt
```

```dos
C:\> ECHO Привет, мир! > test.txt
C:\> DIR
C:\> TYPE test.txt
Привет, мир!
C:\> ECHO Ещё одна строка >> test.txt
C:\> TYPE test.txt
Привет, мир!
Ещё одна строка
```

## 💡 Продвинутые приёмы

### Создать README для проекта:
```dos
ECHO === МОЙ ПРОЕКТ === > readme.txt
ECHO Описание: Тестовый проект >> readme.txt
ECHO Автор: Я >> readme.txt
ECHO Дата: >> readme.txt
DATE >> readme.txt
```

### Создать конфигурационный файл:
```dos
ECHO # Конфигурация > config.ini
ECHO [Settings] >> config.ini
ECHO debug=true >> config.ini
ECHO port=3000 >> config.ini
TYPE config.ini
```

### Создать простой TODO список:
```dos
ECHO TODO СПИСОК > todo.txt
ECHO [ ] Изучить DOS >> todo.txt
ECHO [ ] Попробовать DOCTOR >> todo.txt
ECHO [ ] Создать файлы >> todo.txt
ECHO [x] Прочитать мануал >> todo.txt
TYPE todo.txt
```

## 🎯 Резюме

**Перенаправление вывода** - это мощный инструмент, который позволяет:
- ✅ Быстро создавать файлы
- ✅ Сохранять результаты команд
- ✅ Создавать логи и отчёты
- ✅ Автоматизировать работу

**Помните:**
- `>` = создать/перезаписать файл
- `>>` = добавить к файлу
- Файлы создаются автоматически
- Вывод не показывается на экране (только сохраняется в файл)
