# DOS95

DOS95 — локальная DOS-подобная среда с терминалом, интерфейсом Windows 95, сохраняемой виртуальной файловой системой и необязательным защищённым режимом OpenAI для команды `DOCTOR`.

## Готовая Windows-сборка

Запустите `dist/DOS95.exe`. Установка Node.js, npm или другого дополнительного ПО не требуется. Приложение слушает только `127.0.0.1`, выбирает порт `3000` или следующий свободный порт и открывает DOS-терминал. Введите `WIN95`, чтобы загрузить графическую среду в той же вкладке.

Пользовательские файлы сохраняются в `%LOCALAPPDATA%\DOS95\vfs.json`. Удаление или обновление EXE не удаляет виртуальный диск. Для OpenAI создайте `.env` рядом с EXE; без ключа `DOCTOR` работает как локальная ELIZA.

## Запуск из исходников

Требуются Node.js 24 и npm 11:

```powershell
npm ci
npm run test:setup
npm start
```

Интерфейсы:

- `/`, `/dos` — DOS-терминал;
- `/win95` — прямой адрес Windows 95;
- `/api/health` — локальная проверка состояния.

## Проверка и сборка

```powershell
npm run verify
npm run build:win
npm run smoke:exe
```

Полная release-проверка выполняется командой `npm run release:check`. Она запускает lint, coverage, E2E, аудит зависимостей, сборку и автономный smoke-тест.

## Безопасность

- сервер доступен только через IPv4 loopback и проверяет Host, порт и Origin;
- изменяющие API-запросы требуют случайный токен текущего процесса;
- Helmet/CSP, ограничения размера, сессий и частоты запросов уменьшают поверхность атаки;
- `DOCTOR` нормализует ввод, блокирует явные prompt injection, модерирует ввод/ответ, не получает инструменты и не возвращает API-ключ браузеру;
- `.env`, сертификаты, сборки и пользовательские данные исключены из Git.

Эти меры не дают абсолютной защиты от всех атак и не превращают программу в антивирус, медицинский сервис или песочницу. Не вводите секреты в `DOCTOR` и не распространяйте неподписанный EXE как доверенный production-релиз.
