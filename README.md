# 🖥️ DOS Web System v1.0 - Windows 95 Edition

## 🌟 Особенности

### 🖼️ Windows 95 Interface (НОВОЕ!)
- 🪟 **Графический интерфейс Windows 95** - классический дизайн 1995 года
- 🖥️ **Рабочий стол** - иконки, панель задач, меню "Пуск"
- 📂 **File Explorer** - графический проводник для виртуальной ФС
- 🎨 **Управление окнами** - перетаскивание, изменение размера, Min/Max/Close
- ⏰ **Панель задач** - активные окна, часы, системный трей

### 💻 DOS Terminal
- 🎨 **Ретро DOS интерфейс** - зелёный терминал с CRT эффектами
- 💾 **Виртуальная файловая система** - полная эмуляция DOS файлов и каталогов
- 🤖 **AI Психотерапевт ELIZA** - интеграция с GPT-4O для умных диалогов
- 📁 **26+ DOS команд** - DIR, CD, TYPE, COPY, DEL, DOCTOR и многое другое
- 🎮 **Easter Eggs** - калькулятор, ASCII баннеры, случайные цитаты
- 📜 **История команд** - навигация стрелками вверх/вниз
- ⚡ **Быстрая работа** - мгновенный отклик команд

## 📦 Установка

### Требования

- Node.js >= 14.0.0
- npm или yarn
- OpenAI API ключ (опционально, для команды DOCTOR)

### Шаги установки

1. **Клонируйте или скачайте проект**

```bash
cd dos-web-system
```

2. **Установите зависимости**

```bash
npm install
```

3. **Настройте переменные окружения**

Создайте файл `.env` в корне проекта:

```bash
cp .env.example .env
```

Отредактируйте `.env` файл:

```env
# OpenAI API Key для команды DOCTOR
OPENAI_API_KEY=sk-ваш-ключ-здесь

# Порт сервера (по умолчанию 3000)
PORT=3000

# Модель GPT (по умолчанию gpt-4o)
GPT_MODEL=gpt-4o
```

4. **Запустите сервер**

```bash
npm start
```

Или для режима разработки с автоперезагрузкой:

```bash
npm run dev
```

5. **Откройте браузер**

Перейдите на `http://localhost:3000`

## 🎮 Использование

### Основные команды

#### Файловые операции

```dos
DIR [путь]              Список файлов и каталогов
CD [путь]               Смена каталога
  CD..                  На уровень вверх (без пробела!)
  CD\                   В корень диска
  C:                    Перейти на диск C:\
TYPE <файл>             Просмотр содержимого файла
MORE <файл>             Постраничный просмотр файла
COPY <источник> <цель>  Копирование файла
DEL <файл>              Удаление файла
MD <каталог>            Создание каталога
RD <каталог>            Удаление пустого каталога
REN <старый> <новый>    Переименование файла
MOVE <источник> <цель>  Перемещение файла
TREE [путь]             Дерево каталогов
ATTRIB <файл>           Атрибуты файла
```

#### Системные команды

```dos
CLS                     Очистка экрана
HELP [команда]          Справка по командам
VER                     Версия системы
DATE                    Показать дату
TIME                    Показать время
ECHO <текст>            Вывод текста
SET [переменная]        Переменные окружения
PATH                    Путь поиска программ
VOL                     Метка тома
MEM                     Информация о памяти
EXIT                    Выход
```

#### Специальные команды

```dos
DOCTOR                  AI психотерапевт (GPT-4O)
CALC <выражение>        Калькулятор (например: CALC 2 + 2)
BANNER <текст>          ASCII баннер
FORTUNE                 Случайная цитата
```

#### 📝 Перенаправление вывода

Создавайте файлы прямо из командной строки! Перенаправьте вывод любой команды в файл.

```dos
команда > файл          Создать файл с выводом (перезаписать если существует)
команда >> файл         Добавить вывод к существующему файлу

Примеры:
ECHO Hello World > test.txt        - Создать файл с текстом
DIR > listing.txt                  - Сохранить список файлов
VER > info.txt                     - Сохранить версию системы
ECHO More text >> test.txt         - Добавить текст к файлу
CALC 2 + 2 > result.txt            - Сохранить результат вычисления
FORTUNE > wisdom.txt               - Сохранить случайную цитату
```

**Подробное руководство:** `HELP REDIRECT` или см. файл [REDIRECTION_GUIDE.md](REDIRECTION_GUIDE.md)  
**Быстрое демо:** См. файл [QUICK_REDIRECT_DEMO.md](QUICK_REDIRECT_DEMO.md)

### 🤖 Команда DOCTOR

Команда `DOCTOR` запускает AI психотерапевта на базе GPT-4O, эмулирующего классическую программу ELIZA.

**Пример использования:**

```dos
C:\> DOCTOR

╔═══════════════════════════════════════════════════╗
║      ELIZA - AI Психотерапевт (GPT-4O)            ║
║      Виртуальная терапевтическая сессия           ║
╚═══════════════════════════════════════════════════╝

Здравствуйте. Я ваш AI психотерапевт.
Расскажите мне, что вас беспокоит.

(Введите QUIT для выхода)

YOU> Я чувствую себя уставшим
DOCTOR> Понимаю, усталость может быть тяжелым бременем. 
        Расскажите, что конкретно вас утомляет?

YOU> Работа отнимает все силы
DOCTOR> Работа занимает много вашей энергии. 
        Как давно вы чувствуете такую перегруженность?

YOU> QUIT
Сеанс завершен. Берегите себя!
```

**Важно:** Без OpenAI API ключа команда DOCTOR будет работать в режиме классической ELIZA с простыми паттернами ответов.

## 🎨 Настройка

### Изменение цветовой схемы

Отредактируйте `public/style.css` и измените цвета:

```css
/* Зеленая тема (по умолчанию) */
color: #00ff00;

/* Янтарная тема */
color: #ffaa00;

/* Белая тема */
color: #ffffff;
```

### Добавление новых команд

1. Откройте `commands/handler.js`
2. Добавьте команду в объект `this.commands`
3. Создайте функцию обработчик в соответствующем файле

Пример:

```javascript
// В handler.js
'MYCOMMAND': myCommands.myFunction,

// В myCommands.js
myFunction: (args, session, vfs) => {
    return { output: 'Hello World!\n' };
}
```

### Расширение виртуальной файловой системы

Отредактируйте `filesystem/virtualFS.js` и добавьте файлы в конструктор:

```javascript
'MYFILE.TXT': {
    type: 'file',
    content: 'Содержимое моего файла'
}
```

## 🔧 API Endpoints

### POST /api/command

Выполнить команду

**Request:**
```json
{
    "command": "DIR",
    "sessionId": "session_abc123"
}
```

**Response:**
```json
{
    "success": true,
    "output": "Содержимое каталога...",
    "currentDir": "C:\\",
    "doctorMode": false
}
```

### GET /api/commands

Получить список команд

**Response:**
```json
{
    "commands": {
        "Файловые команды": [...],
        "Системные команды": [...]
    }
}
```

## 🐛 Устранение проблем

### OpenAI API не работает

1. Проверьте наличие API ключа в `.env`
2. Убедитесь, что у вас есть доступ к GPT-4O
3. Проверьте баланс на аккаунте OpenAI
4. Посмотрите логи сервера на наличие ошибок

### Команда DOCTOR возвращает ошибки

Если GPT-4O недоступен, система автоматически переключится на классическую ELIZA без AI.

### Порт 3000 занят

Измените порт в `.env` файле:

```env
PORT=8080
```
