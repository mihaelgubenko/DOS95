# Настройка OpenAI для DOCTOR

Интеграция необязательна: без ключа команда `DOCTOR` использует локальную ELIZA. Ключ хранится только на компьютере пользователя и не включается в EXE.

## Вариант 1: файл `.env` рядом с программой

Для готовой сборки создайте обычный текстовый файл с точным именем `.env` рядом с `DOS95.exe`:

```dotenv
OPENAI_API_KEY=ваш_новый_ключ
GPT_MODEL=gpt-5.6-terra
GPT_REASONING_EFFORT=low
```

Убедитесь, что Windows не добавила расширение `.txt`. После изменения полностью перезапустите программу. Для запуска из исходников файл `.env` должен находиться в корне проекта.

## Вариант 2: переменная среды Windows

На время текущего окна PowerShell:

```powershell
$env:OPENAI_API_KEY="ваш_новый_ключ"
.\dist\DOS95.exe
```

Постоянно для текущего пользователя:

```powershell
[Environment]::SetEnvironmentVariable('OPENAI_API_KEY', 'ваш_новый_ключ', 'User')
```

После постоянной установки откройте новое окно терминала или перезапустите приложение. Файл `.env` удобнее для переносимой копии, а пользовательская переменная среды — если ключ не должен лежать рядом с EXE.

## Выбор модели

По умолчанию используется `gpt-5.6-terra` — рекомендуемый баланс качества, скорости и стоимости. Разрешены только:

- `gpt-5.6-terra` — обычный режим;
- `gpt-5.6-luna` — быстрее и экономнее;
- `gpt-5.6-sol` — максимальное качество, обычно медленнее и дороже.

Неизвестное значение автоматически заменяется на `gpt-5.6-terra`. Допустимые уровни рассуждения: `none`, `low`, `medium`; по умолчанию `low`.

## Встроенная защита

Перед отправкой в модель приложение нормализует и ограничивает ввод, блокирует явные prompt-injection инструкции и проверяет ввод и ответ моделью `omni-moderation-latest`. Запросы выполняются через Responses API без инструментов, с ограниченной историей, `store: false` и анонимным стабильным `safety_identifier`. Ответы с признаками утечки системной конфигурации или ключа не показываются.

Локальный HTTP API принимает изменяющие запросы только с одноразовым токеном процесса, проверяет Origin/Host и ограничивает частоту запросов. Ключ никогда не возвращается браузеру.

Эти меры существенно уменьшают риск, но ни одна LLM-защита не даёт абсолютной гарантии. Не вводите в DOCTOR пароли, платёжные данные, медицинские документы и другие секреты. Программа не является врачом, антивирусом или песочницей и не должна открывать недоверенные файлы.

## Правила обращения с ключом

- Для каждого пользователя создавайте отдельный ключ и лимит расходов.
- Не отправляйте `.env` вместе с EXE и не коммитьте его в Git.
- Если старый ключ кому-либо показывался или попадал в репозиторий, отзовите его и создайте новый — простого удаления файла недостаточно.
- Проверяйте актуальные цены и доступность моделей в панели OpenAI перед выбором.

При ошибке сети, авторизации, модерации или ответа провайдера приложение безопасно переключается на локальную ELIZA без вывода внутренних деталей.
